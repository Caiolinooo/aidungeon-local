# Motor de regras autoritativo + Modo Vida (D20 / d100 / Sims-like)

## Context
Pedido: o jogo deve ser uma simulação completa de aventura/vida; pesquisar o gênero (D&D, FATAL, outros RPGs de mesa, Sims, inZOI), achar o que falta e o que está errado, e planejar a implementação, incluindo um modo de simulação de vida opcional para o RPG.
Decisões do usuário: (1) sistemas = motor JSON data-driven com dois packs enviados, **d20** (D&D 5e; Tormenta20 reutiliza) e **d100** (Call of Cthulhu/BRP); GURPS/FATE/Savage Worlds continuam só prosa (`rulesets`), com apenas rolagem 3d6/4dF no servidor; (2) **Modo Vida** = toggle por aventura (relógio hora/dia/estação, necessidades de jogador e NPCs, rotinas, relações NPC–NPC), usável com ou sem pack de regras; (3) motor **autoritativo**: o servidor rola dados e aplica PV/itens/ouro ANTES da narração; o resultado entra no prompt como o único desfecho possível; ação impossível é recusada antes de gastar tokens do narrador.
Produto em pt-BR. Repo: `/mnt/DEV/Projeto/aidungeon-local` (FastAPI `backend/app`, React `frontend/src`, SQLite).

### 6. Resolução (regras) e Modo Vida
`backend/app/sim/rules.py` — núcleo puro, sem LLM, `rng` injetável:
- `def ensure_actor(state: dict, pack: dict | None, user: str, name: str, sheet_stats: dict | None, legacy_inventory: list | None = None) -> dict`: cria o actor em `state["actors"][actor_key(user)]` se não existir (nunca recria; preserva edições). d20: `abilities = stats.normalize_stats(sheet_stats or {})` (6 chaves); d100: aplicar `ability_scale`/mapeamento do pack. `hp_max`: d20 = `max(1, hp.base + stat_modifier(con))`; d100 = `(con+tam)//10`; `ac` (d20) = `10 + stat_modifier(dex)`; `resources.gold = start_gold`; `resources.san` = valor de `pod` quando o pack tem `san`, senão `None`; `level=1`, `xp=0`, `down=False`. Sem pack: `hp/hp_max/ac=None`, `resources.gold=0`.
- `def resolve(state: dict, pack: dict | None, intent: dict, actor_key_: str, cards: list[dict], penalty: int, rng) -> Resolution`, onde `Resolution = dataclass(steps: list[dict], changes: list[dict], refusal: str|None, card_status: dict[str,str])`. Cada step: `{"label": str, "text": str}`; cada change: `{"who": str, "what": str, "from": int, "to": int}`. Comportamento por `intent["kind"]` (pack ausente ⇒ só `buy`, `take`, `use_item` (sem efeito de cura), `none`):
  - `none`: nada.
  - `skill`/`save` (d20): `ability = ability_alias[intent.ability or "wis"]`; rola `roll_d20(rng, intent.advantage)`; total = d20 + `stat_modifier(abilities[ability])` + (prof se `fold(intent.skill)` ∈ `fold(proficient)`; prof = `2 + (level-1)//4`) − `penalty`; alvo = `dc[intent.difficulty]`; sucesso se total ≥ alvo; `total ≥ alvo+10` → rótulo "sucesso excepcional", `total ≤ alvo-10` → "fracasso desastroso". Texto: `"Atletismo (FOR): d20 14 +3 = 17 vs CD 15 — SUCESSO"`.
  - `skill`/`save` (d100): alvo base = `skills[fold(skill)]` se existir no actor, senão do pack, senão `abilities[ability_alias[ability]]` se `intent.ability`, senão `skill_default`; `alvo = max(1, base − penalty*10) * difficulty[...]` arredondado para baixo; rola `roll_d100`; nível: ≤ alvo//5 extremo, ≤ alvo//2 difícil, ≤ alvo sucesso, senão falha; 1 = crítico; 100 (ou ≥96 se `base < 50`) = desastre. Texto: `"Furtividade: d100 34 vs 40 — SUCESSO"`.
  - `attack`: foe = `_find_or_create_foe(state, pack, intent)` (chave = slug `fold(target)` com espaços→`-`; se `target==""` usa `"inimigo"`; se existir card `type=="character"` com `fold(title)==fold(target)` guarda `card_id`; stats vêm de `pack["toughness"][intent.toughness or "normal"]`; foe morto não pode ser atacado de novo: `refusal = "{nome} já está morto."`). Se `actor.down` → `refusal = "Seu personagem está caído e não pode atacar."`. Arma: maior chave de `pack["weapons"]` contida em `fold(intent.weapon)` (senão `desarmado`). d20: ataque = d20 + mod(arma.ability) + prof − penalty vs `foe.ac`; 1 natural erra, 20 natural acerta com dano de dados dobrado; dano = `roll(dice)` (+ dados de novo se crítico) + mod, mínimo 1 no acerto; d100: alvo = skill da arma como acima; sucesso extremo = dano máximo dos dados (`roll_max`) + rolagem extra. Aplica `foe.hp -= dano`; `foe.hp <= 0` ⇒ `foe.dead=True`, XP do pack ao actor (level up d20: `xp_levels`; sobe `hp_max += max(1, per_level + mod(con))`, `hp` igual; step "Nível N!"), ouro = `roll(toughness.gold)` (d20; d100 nada) somado a `resources.gold`, `card_status[card_id] = "dead"` quando `card_id`. Se foe sobrevive e `intent.hostile`: contra-ataque — d20: `d20 + foe.atk` vs `actor.ac` (1 erra, 20 crítico); d100: `roll_d100 <= foe.atk`; dano = `roll(foe.dmg)` (dobra dados no crítico); `actor.hp = max(0, hp - dano)`; `hp == 0` ⇒ `actor.down = True` + step "Você caiu (0 PV)".
  - `use_item`: item deve existir (casamento `fold` por substring) em `actor.inventory`, senão `refusal = "Você não tem '{item}' no inventário (a aba Vida/Regras permite adicioná-lo)."`; se o item casa com `pack["consumables"]` e tem `heal`: `hp = min(hp_max, hp + roll(heal))`, `down=False`, remove 1 unidade (apaga a linha se qty chega a 0); outros itens apenas confirmam a presença (sem consumo).
  - `buy`: `gold` > `resources.gold` ⇒ `refusal = "Ouro insuficiente: precisa de {gold}, tem {have}."`; senão `resources.gold -= gold`, `+1` do `intent.item` no inventário (cria linha).
  - `take`: `+1` do `intent.item` no inventário (sem item ⇒ nada).
  - `rest`: `minutes ≥ 360` ⇒ `hp = hp_max`, `down=False`; `60 ≤ minutes < 360` ⇒ `hp = min(hp_max, hp + hp_max//4)`; sem HP no pack ⇒ nada.
  - Teste de Sanidade (d100): se `intent.shock != "none"` e `resources.san is not None`: `roll_d100 <= san` ⇒ perda `sanity_loss[shock][0]`, senão `[1]` (expressão de dado; `"0"` = zero); `san = max(0, san - perda)`; perda ≥ 5 ⇒ step extra "Insanidade temporária"; `san == 0` ⇒ step "Loucura indefinida".
  - Toda mudança numérica entra em `changes` com `from`/`to`.
- `def build_block(steps, changes, time_info, refusal) -> str` → texto para o narrador:

  ```
  <um passo por linha, "text" de cada step>

  Tempo: +10 min (agora 08:10, dia 1).   (só quando Modo Vida)
  Regra: narre exatamente este resultado. Não invente outro dano, cura, ganho ou perda de item/ouro. Não mencione números, dados nem este bloco ao jogador.
  ```
